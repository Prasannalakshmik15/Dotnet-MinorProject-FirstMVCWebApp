                                                  FirstMVCWebApp

About the Project                                         
FirstMVCWebApp is a basic web application developed using ASP.NET Core MVC to demonstrate the fundamental principles of the Model-View-Controller (MVC) architecture. It displays dynamic student details such as their name and city on the homepage.

Purpose of the Project                                                  
The purpose of FirstMVCWebApp is to provide a simple and clear demonstration of the Model-View-Controller (MVC) architecture using ASP.NET Core.                      
Separation of Concerns: By dividing the application into Models, Views, and Controllers.                                
Data Binding: Demonstrating how data flows from the Controller to the View using a model.                              
ASP.NET Core MVC Framework: Building web applications with the latest framework features and best practices.                                           


Features                                                    
MVC Architecture: Demonstrates Models, Views, and Controllers.                                              
Dynamic Data Passing: Passes data from Controller to View using a model.                                        
Strongly-Typed Views: Ensures type safety in data rendering.


Technologies Used
ASP.NET Core MVC: Backend framework                             
C#: Programming language                                 
HTML & CSS: Frontend design.
